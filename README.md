# 카보로딩 트래커

마라톤 전 3일 카보로딩 동안 탄수화물과 수분 섭취를 기록하는 모바일 웹앱입니다.
대회를 앞두고 직접 쓰려고 만들었습니다.

## 기능

- **자동 목표 계산**: 대회 날짜와 체중을 넣으면 로딩 3일과 대회 당일 아침 목표가 계산됩니다.
- **진행률 표시**: 원형 게이지와 진행률에 따라 바뀌는 응원 문구로 하루 목표 대비 섭취량을 보여줍니다.
- **세 가지 기록 방법**:
  - 직접 입력 (성분표 기준)
  - 음식 목록 검색 (0.5·1·1.5인분)
  - 사진이나 설명으로 Claude가 탄수화물 추정
- **날짜별 안내**: 50g 단위 나눠 먹기, 수분 섭취, 대회 아침 식사, 레이스 중 보급을 안내합니다.
- **동기부여 화면**: 내 러닝 사진과 문구가 첫 화면에서 번갈아 나옵니다.
- **홈 화면 설치**: 홈 화면에 추가해서 앱처럼 쓸 수 있습니다.

## 목표량 기준

[Featherstone Nutrition](https://www.featherstonenutrition.com)의 카보로딩 가이드와 레이스 영양 가이드를 따릅니다.

| 구분 | 탄수화물 | 수분 |
|---|---|---|
| 대회 3일 전 ~ 1일 전 | 하루 8g/kg | 체중(lb)÷2 oz + 30oz |
| 대회 당일 아침 | 체중(lb)÷2 g (약 1.1g/kg, 최소 75g) | 이온음료 300~350ml |

모든 값은 설정에서 바꿀 수 있습니다. 일반적인 안내이며 개인 차이가 있을 수 있습니다.

## 개인정보

서버가 없습니다.

- **기록, 설정, 사진**: 각자의 브라우저(localStorage, IndexedDB)에만 저장됩니다.
- **Claude API 키**: 사진 추정에만 쓰입니다. 입력한 기기에만 저장되고 Anthropic API로만 전송됩니다.

- Anthropic TypeScript SDK (브라우저에서 사진 추정 호출)
